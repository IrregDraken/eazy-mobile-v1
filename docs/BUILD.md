# Eazy V1 Build Contract

1. Install Flutter 3.29 or newer.
2. Run flutter create . --platforms=android,ios.
3. Run flutter pub get.
4. Add native Firebase configuration for project eazy-24e6.
5. Run flutter analyze and flutter test.
6. Run flutter run on a physical device.

Do not copy visual assets from either previous Eazy repository into this project.
